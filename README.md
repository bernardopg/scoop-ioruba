# Ioruba Scoop bucket

Install the [Ioruba](https://github.com/bernardopg/ioruba) Windows package:

```powershell
scoop bucket add ioruba https://github.com/bernardopg/scoop-ioruba
scoop install ioruba
```

`ioruba.json` is generated from Ioruba's published NSIS installer and its SHA-256 checksum on every tagged release.
